# lllc — ll-lang compiler for Python

[![PyPI](https://img.shields.io/pypi/v/lllc)](https://pypi.org/project/lllc/)
[![Build & Test](https://github.com/Neftedollar/ll-lang/actions/workflows/build.yml/badge.svg)](https://github.com/Neftedollar/ll-lang/actions/workflows/build.yml)

**ll-lang compiler** — write once in a minimal statically-typed functional language, compile to **Python** (and F#, TypeScript, Java, C#).

```lll
module App

-- ll-lang source
greet(name Str) Str = "Hello, " ++ name ++ "!"

Result A E = Ok A | Err E

safeDivide(a Float)(b Float) Result[Float, Str] =
  if b == 0.0
    Err "division by zero"
  else Ok (a / b)
```

Compiles to idiomatic Python:

```python
# app.py — generated by lllc
from __future__ import annotations
from dataclasses import dataclass
from typing import Union

def greet(name: str) -> str:
    return "Hello, " + name + "!"

@dataclass
class Ok:
    value: float

@dataclass
class Err:
    error: str

Result = Union[Ok, Err]

def safe_divide(a: float, b: float) -> Result:
    if b == 0.0:
        return Err("division by zero")
    return Ok(a / b)
```

## Install

Requires **Python ≥ 3.9**. No .NET needed for Python output.

```bash
pip install lllc
```

## Quick start

```bash
# Create a file
cat > hello.lll << 'EOF'
module Hello

main() = print("Hello, ll-lang!")
EOF

# Compile to Python
lllc build --target py hello.lll
# → hello.py

# Compile and run
lllc run --target py hello.lll
# Hello, ll-lang!

# Type-check only (no output)
lllc check --target py hello.lll
```

## Why ll-lang?

- **No ceremony** — no braces, no `def`, no `class` boilerplate. Types are uppercase, values are lowercase.
- **Hindley-Milner inference** — write functions without type annotations; the compiler infers everything.
- **Algebraic data types** — sum types → Python `@dataclass` + `Union`, with exhaustiveness checks at compile time.
- **One source, five targets** — same `.lll` file compiles to Python, TypeScript, F#, Java, and C#.
- **LLM-optimized** — compact error format (`E001 12:5 TypeMismatch`) designed for AI agents.

## Same source → all targets

```bash
lllc build app.lll                # → app.fs   (F#)
lllc build --target ts   app.lll  # → app.ts   (TypeScript)
lllc build --target py   app.lll  # → app.py   (Python)
lllc build --target java app.lll  # → app.java (Java 21)
lllc build --target cs   app.lll  # → app.cs   (C#)
```

## CLI reference

```
lllc build [--target py] <file.lll>   compile single file
lllc build [--target py] [dir]        compile project (reads lll.toml)
lllc check [--target py] <file.lll>   type-check only, no output
lllc run   [--target py] <file.lll>   compile and run via python3
lllc new   <name>                     scaffold new project
lllc mcp                              run MCP server (for Claude Code / Cursor)
```

## Language in 30 seconds

```lll
module Examples

-- value binding
pi = 3.14159

-- curried function with type annotation
add(a Int)(b Int) Int = a + b

-- sum type → Python @dataclass + Union
Shape = Circle Float | Rect Float Float

-- exhaustive pattern match (compiler enforces all cases)
area(s Shape) Float =
  match s
    | Circle r -> pi * r * r
    | Rect w h -> w * h

-- parametric type
Maybe A = Some A | None

-- type-safe tag (zero-cost wrapper, erased at runtime)
tag UserId

getUser(id Str[UserId]) Maybe[Str] = Some "alice"
```
