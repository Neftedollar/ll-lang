# Express-style HTTP server in ll-lang

A minimal Express server with routes declared entirely in `.lll` source and
served by Node/Bun. Demonstrates the per-project FFI overlay landed in
commit `fa25254` (closes [#155](https://github.com/Neftedollar/ll-lang/issues/155)).

## Run it

```bash
cd examples/express-todo

# 1. compile Main.lll → bin/typescript/ExpressTodo.ts
lllc build --target ts .

# 2. install Express
bun install

# 3. run the generated TypeScript
bun run bin/typescript/ExpressTodo.ts &

# 4. hit the routes declared from ll-lang
curl localhost:3000/hello
# → Hello from ll-lang

curl localhost:3000/health
# → ok

kill %1
```

Works with Bun (recommended, native `.ts`) or `node --experimental-strip-types`.

## What's in each file

| File                            | Role                                                                 |
|---------------------------------|----------------------------------------------------------------------|
| `src/Main.lll`                  | ll-lang source: declares externals, routes, and starts the server    |
| `lll.toml`                      | Project manifest + `[platform.typescript.externals]` FFI mappings    |
| `package.json`                  | npm manifest; depends on `express`                                   |
| `bin/typescript/ExpressTodo.ts` | Generated by `lllc build --target ts .` (do not edit)                |

**No hand-written TypeScript shim.** The entire server behavior is defined in
`src/Main.lll` — the `.ts` output is a straight translation with Express
bindings spliced in from `lll.toml`.

## How FFI works

`src/Main.lll` declares opaque types and externals the usual way:

```lll
opaque ExpressApp
opaque Req
opaque Res

external expressApp() ExpressApp
external appGet(app ExpressApp)(path Str)(handler Req -> Res -> Int) Int
external resSend(res Res)(body Str) Int
external appListen(app ExpressApp)(port Int) Int
```

`lll.toml` provides the TypeScript-side implementations:

```toml
[platform.typescript.externals]
"expressApp" = "require('express')()"
"appGet"     = "(app) => (path) => (handler) => { app.get(path, (req, res) => handler(req)(res)); return 0; }"
"resSend"    = "(res) => (body) => { res.send(body); return 0; }"
"appListen"  = "(app) => (port) => { app.listen(port); return 0; }"
```

The TypeScript codegen splices each expression verbatim at the top of the
generated `.ts`, so `expressApp` becomes a real Express instance and `appGet`
becomes a curried function over that instance. ll-lang `main()` then calls
these the same way it calls any other `external`.

Generated excerpt:

```ts
const expressApp: any = require('express')();
const appGet: any = (app) => (path) => (handler) => { app.get(path, (req, res) => handler(req)(res)); return 0; };
const resSend: any = (res) => (body) => { res.send(body); return 0; };
const appListen: any = (app) => (port) => { app.listen(port); return 0; };

function main(): void {
  // ...app, appGet, resSend, appListen composed from Main.lll...
}
main();
```

## Extending to more routes

Add a new external in `Main.lll` + a new mapping in `lll.toml`. Nothing else
needs to change — no shim to edit, no TypeScript glue to write.

Example: add POST support.

```lll
external appPost(app ExpressApp)(path Str)(handler Req -> Res -> Int) Int
external reqBody(req Req) Str
```

```toml
"appPost"  = "(app) => (path) => (handler) => { app.post(path, express.json(), (req, res) => handler(req)(res)); return 0; }"
"reqBody"  = "(req) => JSON.stringify(req.body)"
```

## Known limits (today)

- **No ll-lang mutable store.** For a real TODO API that accepts `POST /todos`
  and remembers the list, the store lives in the TS expression (e.g. a
  closure-captured array). ll-lang 1.x has no `IORef`/`State` primitive.
- **Externals are spliced raw.** The TS backend does no type-checking or
  sandboxing of the overlay expressions — they are your responsibility.
- **TypeScript target only (today).** Same overlay pattern for Python, C#,
  Java, F# is tracked in [#156](https://github.com/Neftedollar/ll-lang/issues/156).

## Rebuild after editing `Main.lll` or `lll.toml`

```bash
lllc build --target ts .
bun run bin/typescript/ExpressTodo.ts
```
